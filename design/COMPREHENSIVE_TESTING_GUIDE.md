## 测试环境准备

### 1.1 环境检查清单

**开发环境测试**:
```bash
# 1. 确认端口可用
./scripts/check-server.sh

# 2. 检查依赖版本
node --version  # 需要 18+
npm --version
yarn --version

# 3. 检查环境变量
cd api
cat .env.production.example

# 应该配置的变量：
# - DEEPSEEK_API_KEY
# - SILICONFLOW_API_KEY (或其他 embedding provider)
# - QDRANT_URL 或 VECTOR_DB_PATH
```

**生产环境测试**:
```bash
# 1. SSH 登录服务器
ssh root@wiki.camthink.ai

# 2. 检查 PM2 进程
pm2 status wiki-api

# 3. 检查 Nginx 状态
systemctl status nginx

# 4. 检查磁盘空间
df -h /var/www/wiki-api

# 5. 检查向量数据库
ls -lh /var/www/wiki-api/data/vectors.db
# 或
curl http://localhost:3001/api/health
```

### 1.2 快速测试命令

```bash
# 开发环境 - 完整测试和重启
./scripts/test-and-restart.sh --with-api

# 开发环境 - 快速测试（不重启）
./scripts/test-api.sh --quick

# 开发环境 - 仅测试 API
./scripts/test-api.sh

# 生产环境 - 部署和测试
./scripts/test-and-restart.sh --production --with-api
```

## 测试场景清单

### 2.1 功能测试（Functional Tests）

#### 基础功能
- [ ] **健康检查端点**
  - [ ] GET `/api/health` 返回 200
  - [ ] 响应时间 < 1s
  - [ ] 返回 "healthy" 文本

- [ ] **聊天端点 - 中文**
  - [ ] POST `/api/chat` 接受中文查询
  - [ ] 返回 SSE 流（`data: type: chunk`）
  - [ ] 回答内容相关（包含 NE301、NE101、NG4500 等关键词）
  - [ ] 来源引用正确（`data: type: sources`）

- [ ] **聊天端点 - 英文**
  - [ ] POST `/api/chat` 接受英文查询
  - [ ] 自动检测语言并使用英文回答
  - [ ] 来源链接正确

- [ ] **来源引用展示**
  - [ ] 点击来源链接可跳转到正确文档页面
  - [ ] 来源标题正确显示
  - [ ] 来源摘要（excerpt）准确

#### 高级功能
- [ ] **多轮对话**
  - [ ] API 能处理 conversation_id
  - [ ] 对话历史被正确传递
  - [ ] 后续问题使用前文上下文

- [ ] **跨文档对比**
  - [ ] 查询 "NE101 vs NE301" 能返回对比结果
  - [ ] 来源包含两个产品的文档
  - [ ] 回答结构化（表格或列表）

- [ ] **追问建议**
  - [ ] 返回 `data: type: suggestions` 事件
  - [ ] 建议问题相关且可操作

- [ ] **Agent 路径触发**
  - [ ] 复杂问题触发 Agent 路径
  - [ ] 返回 `data: type: progress` 事件
  - [ ] 进度提示清晰（"正在检索..."、"正在分析..."）

### 2.2 性能测试（Performance Tests）

- [ ] **响应时间**
  - [ ] P50 < 3s（50% 查询）
  - [ ] P95 < 5s（95% 查询）
  - [ ] P99 < 8s（99% 查询）

- [ ] **并发处理**
  - [ ] 同时 10 个请求正常处理
  - [ ] 无请求丢失
  - [ ] 无内存溢出

- [ ] **SSE 稳定性**
  - [ ] SSE 连接保持 30+ 秒
  - [ ] 无意外断开
  - [ ] chunk 间隔合理（< 500ms）

- [ ] **向量检索性能**
  - [ ] 检索延迟 < 1s
  - [ ] 重排序延迟 < 2s
  - [ ] 总体 RAG 延迟 < 3s

### 2.3 安全测试（Security Tests）

#### 输入验证
- [ ] **空消息拒绝**
  - [ ] 返回 HTTP 400 或 422
  - [ ] 错误信息清晰

- [ ] **超长消息拒绝**
  - [ ] 消息 > 500 字符被拒绝
  - [ ] 返回 HTTP 413 或 400

- [ ] **无效 JSON 拒绝**
  - [ ] 格式错误的 JSON 返回 400
  - [ ] 不导致服务器崩溃

- [ ] **XSS 防护**
  - [ ] 输入 `<script>` 标签被转义
  - [ ] 返回内容不包含可执行脚本
  - [ ] Markdown 渲染器安全

#### 速率限制
- [ ] **请求频率限制**
  - [ ] 每分钟 10 次限制生效
  - [ ] 超限后返回 HTTP 429
  - [ ] 限制后自动恢复

- [ ] **每日上限**
  - [ ] 每日 100 次限制生效
  - [ ] 超限后返回友好错误信息

#### CORS 和安全头
- [ ] **CORS 配置**
  - [ ] `Access-Control-Allow-Origin` 存在
  - [ ] 仅允许 `https://wiki.camthink.ai`
  - [ ] OPTIONS 预检请求正常处理

- [ ] **安全头**
  - [ ] `X-Frame-Options: SAMEORIGIN`
  - [ ] `X-Content-Type-Options: nosniff`
  - [ ] `X-XSS-Protection: 1; mode=block`
  - [ ] `Strict-Transport-Security` 存在

### 常见问题排查

| 问题 | 检查命令 | 解决方法 |
|------|---------|----------|
| API 无法启动 | `pm2 logs wiki-api --err` | 检查环境变量配置 |
| SSE 连接中断 | `pm2 logs \| grep timeout` | 检查 Nginx proxy_read_timeout |
