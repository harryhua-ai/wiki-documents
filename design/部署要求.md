## 自动部署流程

### 📦 静态网站部署

**Workflow 文件**: `.github/workflows/deploy.yml`

**触发条件**:
- 推送到 `main` 分支
- 手动触发 (workflow_dispatch)

**部署流程**:

```yaml
1. 环境配置
   NODE_ENV: production
   DEPLOY_ENV: production
   SITE_URL: https://wiki.camthink.ai
   BASE_URL: /

2. 构建静态网站
   yarn install --frozen-lockfile
   yarn build

3. 部署到云服务器
   使用 rsync 同步 build/ 目录
   到 $TARGET_PATH

4. 完成
   静态网站立即生效
```

### 🚀 API 服务部署

**Workflow 文件**: `.github/workflows/deploy-api.yml`

**触发条件**:
- 推送到 `main` 分支 **且** `api/` 目录有改动
- 手动触发 (workflow_dispatch)

**部署流程**:

```yaml
1. 构建 API
   cd api
   npm ci
   npm run build

2. 创建部署包
   打包必要文件 (排除 node_modules)
   tar -czf wiki-api-deploy.tar.gz

3. 上传到服务器
   通过 SSH 上传到 $API_DEPLOY_PATH

4. 服务器端操作
   - 解压部署包
   - npm ci --production (安装依赖)
   - pm2 reload wiki-api (零停机重启)

5. 健康检查
   curl $API_HEALTH_URL
   等待 200 响应

6. 完成
   API 服务自动重启并运行
```

## GitHub Secrets 配置

### 必需配置项

在 GitHub 仓库设置中配置以下 Secrets：

| Secret 名称 | 说明 | 示例 |
|------------|------|------|
| `SERVER_HOST` | 云服务器地址 | `wiki.camthink.ai` 或 IP |
| `SERVER_USER` | SSH 登录用户名 | `root` 或 `ubuntu` |
| `SSH_PRIVATE_KEY` | SSH 私钥 | `-----BEGIN RSA PRIVATE KEY-----` |
| `SERVER_PORT` | SSH 端口 (可选) | `22` (默认) |
| `TARGET_PATH` | 静态文件部署路径 | `/var/www/wiki-documents` |
| `API_DEPLOY_PATH` | API 部署路径 | `/var/www/wiki-api` |
| `API_HEALTH_URL` | API 健康检查 URL | `http://localhost:3001/health` |

### 配置步骤

1. **生成 SSH 密钥对** (如果还没有):

```bash
# 在本地生成
ssh-keygen -t rsa -b 4096 -C "github-actions" -f ~/.ssh/github_actions_key

# 公钥添加到服务器
ssh-copy-id -i ~/.ssh/github_actions_key.pub user@your-server.com

# 或者手动添加到服务器
cat ~/.ssh/github_actions_key.pub | ssh user@server "cat >> ~/.ssh/authorized_keys"
```

2. **在 GitHub 仓库中配置**:

   - 进入仓库 Settings → Secrets and variables → Actions
   - 点击 "New repository secret"
   - 添加上述每个 Secret

## 服务器端配置要求

### 系统要求

- **操作系统**: Ubuntu 20.04+ / Debian 11+ / CentOS 8+
- **Node.js**: v20.x
- **内存**: 最低 2GB (推荐 4GB+)
- **存储**: 最低 20GB (用于日志、数据库等)

### 必需软件安装

```bash
# 1. 安装 Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. 安装 PM2 (进程管理器)
sudo npm install -g pm2

# 3. 安装 Nginx (Web 服务器)
sudo apt-get install -y nginx

# 4. 安装 Git (用于拉取代码)
sudo apt-get install -y git

# 验证安装
node --version  # v20.x.x
npm --version   # 10.x.x
pm2 --version   # 5.x.x
nginx -v        # 1.18.x
```

### 目录结构

```bash
/var/www/
├── wiki-documents/          # 静态网站根目录
│   ├── build/              # Docusaurus 构建输出
│   │   ├── index.html
│   │   ├── docs/
│   │   ├── assets/
│   │   └── img/
│   └── .nojekyll          # GitHub Pages 兼容
│
└── wiki-api/               # API 服务目录
    ├── dist/              # 编译后的 API 代码
    ├── src/               # 源代码 (部署时包含)
```

### Nginx 配置示例

创建 `/etc/nginx/sites-available/wiki.camthink.ai`:

```nginx
# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name wiki.camthink.ai;
    return 301 https://$server_name$request_uri;
}

# HTTPS 主配置
server {
    listen 443 ssl http2;
    server_name wiki.camthink.ai;

    # SSL 证书配置 (使用 Let's Encrypt)
    ssl_certificate /etc/letsencrypt/live/wiki.camthink.ai/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/wiki.camthink.ai/privkey.pem;

    # 静态文件根目录
    root /var/www/wiki-documents/build;
    index index.html;

    # 启用 gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;

    # 静态网站路由
    location / {
        try_files $uri $uri/ /index.html;
        expires 1h;
        add_header Cache-Control "public, immutable";
    }

    # 图片和静态资源
    location /img/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    location /assets/ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
}
```

启用配置:

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/wiki.camthink.ai /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

## 完整部署流程

### 🚀 首次部署指南

#### 步骤 1: 服务器准备

```bash
# SSH 登录到服务器
ssh user@wiki.camthink.ai

# 安装依赖
sudo apt-get update
sudo apt-get install -y nodejs npm git nginx

# 安装 PM2
sudo npm install -g pm2

# 创建目录
sudo mkdir -p /var/www/wiki-documents
sudo mkdir -p /var/www/wiki-api/logs
sudo mkdir -p /var/www/wiki-api/data

# 设置权限
sudo chown -R $USER:$USER /var/www/wiki-documents
sudo chown -R $USER:$USER /var/www/wiki-api
```

#### 步骤 2: 配置环境变量

```bash
cd /var/www/wiki-api

# 从示例创建配置
cp .env.production.example .env.production

# 编辑配置 (填入真实的 API 密钥)
vim .env.production
```

#### 步骤 3: 配置 Nginx

```bash
# 复制上面的 Nginx 配置
sudo vim /etc/nginx/sites-available/wiki.camthink.ai

# 启用配置
sudo ln -s /etc/nginx/sites-available/wiki.camthink.ai /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 配置防火墙 (如果启用)
sudo ufw allow 'Nginx Full'
```

#### 步骤 4: 手动首次部署 (可选)

如果您想手动首次部署而不等待 GitHub Actions:

```bash
# 拉取代码
cd /var/www
git clone https://github.com/camthink-ai/wiki-documents.git wiki-documents-temp

# 部署静态网站
cd wiki-documents-temp
yarn install
yarn build
cp -r build/* /var/www/wiki-documents/

# 部署 API
cd api
npm ci
npm run build
cp -r dist src node_modules package.json /var/www/wiki-api/

# 启动 API
cd /var/www/wiki-api
pm2 start pm2.config.js
pm2 save
pm2 startup  # 生成开机启动脚本

# 清理临时文件
rm -rf /var/www/wiki-documents-temp
```

#### 步骤 5: 配置 SSL 证书 (使用 Let's Encrypt)

```bash
# 安装 Certbot
sudo apt-get install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d wiki.camthink.ai

# 自动续期
sudo crontab -e
# 添加这一行:
0 0 * * * certbot renew --quiet
```

#### 步骤 6: 验证部署

```bash
# 检查静态网站
curl -I https://wiki.camthink.ai

# 检查 API
curl https://wiki.camthink.ai/api/health

# 查看 PM2 状态
pm2 status

# 查看 API 日志
pm2 logs wiki-api --lines 50
```

## 常见问题与排查

### 问题 1: API 服务无法启动

**症状**: PM2 显示应用处于 `errored` 状态

**排查步骤**:

```bash
# 1. 查看详细日志
pm2 logs wiki-api --lines 100

# 2. 检查环境变量
cd /var/www/wiki-api
cat .env.production

# 3. 手动运行测试
node dist/index.js

# 常见原因:
# - .env.production 文件不存在
# - API 密钥无效
# - 端口 3001 被占用
# - node_modules 未安装
```

**解决方法**:

```bash
# 重新安装依赖
cd /var/www/wiki-api
rm -rf node_modules
npm ci --production

# 重启服务
pm2 restart wiki-api
```

### 问题 2: 静态网站显示空白页

**症状**: 访问 https://wiki.camthink.ai 显示空白

**排查步骤**:

```bash
# 1. 检查 build 目录
ls -la /var/www/wiki-documents/build/index.html

# 2. 检查 Nginx 配置
sudo nginx -t

# 3. 查看 Nginx 错误日志
sudo tail -f /var/log/nginx/error.log

# 4. 测试静态文件权限
sudo chown -R www-data:www-data /var/www/wiki-documents
```

**解决方法**:

```bash
# 确保 build 目录存在且有文件
cd /var/www/wiki-documents
ls -la

# 重新触发部署
# 在 GitHub 仓库中手动触发 workflow
```

### 问题 3: API 请求 404

**症状**: 前端调用 `/api/chat` 返回 404

**排查步骤**:

```bash
# 1. 检查 Nginx 配置中的 location /api/
sudo vim /etc/nginx/sites-available/wiki.camthink.ai

# 2. 验证代理配置
proxy_pass http://localhost:3001;

# 3. 测试 API 直接访问
curl http://localhost:3001/health

# 4. 检查 PM2 状态
pm2 status
```

**解决方法**:

```bash
# 重启 Nginx
sudo systemctl reload nginx

# 重启 API
pm2 restart wiki-api
```

### 问题 4: GitHub Actions 部署失败

**症状**: GitHub Actions 显示红色 ❌

**排查步骤**:

1. **查看 Actions 日志**:
   - 进入 GitHub 仓库 → Actions
   - 点击失败的工作流
   - 展开失败的步骤查看详细日志

2. **常见错误**:

```
❌ "Permission denied (publickey)"
   → SSH 密钥配置错误
   → 检查 SSH_PRIVATE_KEY Secret

❌ "Host key verification failed"
   → 服务器指纹未验证
   → 在 workflow 中添加 SSH 扫描步骤

❌ "rsync: command not found"
   → 服务器未安装 rsync
   → sudo apt-get install rsync

❌ "API health check failed"
   → API 未成功启动
   → 检查服务器上的 PM2 状态
```

### 问题 5: 文档搜索无结果

**症状**: Ask AI 功能返回 "未找到相关文档"

**排查步骤**:

```bash
# 1. 检查数据库文件
ls -lh /var/www/wiki-api/data/chat.db

# 2. 查看摄取日志
pm2 logs wiki-api | grep "ingest"

# 3. 检查文档是否被摄取
cd /var/www/wiki-api
sqlite3 data/chat.db "SELECT COUNT(*) FROM documents;"

# 4. 手动重新摄取
cd /var/www/wiki-api
npm run ingest
```

**解决方法**:

```bash
# 强制重新摄取
cd /var/www/wiki-api
npm run ingest:force

# 或在服务器上运行
node dist/scripts/ingest.js --force
```

## 安全建议

### 基本安全措施

1. **防火墙配置**:
```bash
sudo ufw enable
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
```

2. **定期更新**:
```bash
sudo apt-get update
sudo apt-get upgrade
```

3. **限制 SSH 访问**:
```bash
# 编辑 SSH 配置
sudo vim /etc/ssh/sshd_config

# 禁用密码登录
PasswordAuthentication no

# 只允许密钥登录
PubkeyAuthentication yes

# 重启 SSH
sudo systemctl restart sshd
```

4. **API 速率限制**:
   - 已在代码中配置 `express-rate-limit`
   - 防止 API 滥用

### 环境变量安全

```bash
# 设置文件权限
chmod 600 /var/www/wiki-api/.env.production

# 确保密钥不被提交到 Git
echo ".env.production" >> .gitignore
```
